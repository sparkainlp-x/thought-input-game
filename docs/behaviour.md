# Measured behaviour of the memory and the gate

Generated by `node scripts/behaviour.js` from `src/membrane.js`. Do not edit by hand: `npm run behaviour:check` fails if this file is stale.

**SYNTHETIC toy.** Every number below comes from drawn 12 x 12 patterns (eight fixed glyphs, plus generated fragments, flips and random scatter) run through the game's own `project` function. The numbers describe this toy memory on these patterns. They are not a measurement of any brain, signal, device or optical hologram, and they do not predict how a person plays. Sampling uses a seeded generator, so the file is reproducible; 1000 random probes per stored thought per cell of each table (standard error of a rate near 50% is about 0.6 points for 8 thoughts and 0.9 points for 3).

Memory order is the game's: Heart, Star, Tree are stored first; Moon, Eye, Arrow, Spiral, Orbit are added one per won round. "N thoughts" below means the first N of those. `exact` means the recalled pattern equals the stored one cell for cell; `recalled` is the right thought with some cells different; `crosstalk` is the gate accepting a different thought; `refused` is the gate saying no (cosine below tau = 0.35, or fewer than 3 lit cells).

## 6. The game's random number generator

The game draws its round targets, fragment cells and scrambles from a small linear congruential generator (seed 1234567). Written in JavaScript, `state * 1103515245` exceeds 2^53, so the result is not the integer LCG it was meant to be. It is still deterministic and identical in every engine (IEEE doubles), which is why the game keeps it unchanged: play stays identical. The tests and this script use a separate, well-defined generator (mulberry32) for sampling.

- Distinct states reached: 12889; lead-in 2423 draws, then a cycle of 10466 draws.
- 12-bin histogram of the first 100000 draws: 8770, 8364, 8654, 8216, 8473, 8709, 7976, 7918, 8146, 8229, 8109, 8436.
- First three values: 0.943746, 0.500528, 0.561789.

For a game with a few draws per round this is harmless. It is not suitable for statistics, so the tables above use mulberry32 (`Membrane.createMulberry32`, period 2^32, exact integer arithmetic through `Math.imul`). `Membrane.createRng(seed, "mulberry32")` selects it; `createRng(seed)` is still the legacy generator the game uses.

## 8. The store warning: closest neighbour, not the last one

When a drawn pattern is stored, the game warns if it overlaps a stored thought by more than 0.7 (Jaccard) and names that thought. The original named the last stored thought above 0.7; it now names the closest one. This only changes which name is shown; the stored pattern, recall, gate and score are not affected. ## Reading these numbers honestly

- Fragments here contain only correct cells. A person draws wrong cells too; section 3 is the closest proxy.
- The patterns are eight hand-drawn glyphs that share many lit cells (Section 5). Other pattern sets would give different numbers.
- The memory is a list of stored patterns compared one by one with the probe, then combined as a match-weighted sum. It is not a trained weight matrix, and these results say nothing about capacity of real associative memories or holograms.
